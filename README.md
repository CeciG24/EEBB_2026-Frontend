# EEBB_2026-Frontend
Repositorio del desarrollo web para el Encuentro Estudiantil de Biotecnología BUAP 2026 (EEBB 2026). El proyecto incluye una landing page informativa con detalles del evento, modalidades de inscripción y cronograma de actividades, así como un sistema de inicio de sesión y dashboard para la gestión y experiencia de los usuarios registrados.
